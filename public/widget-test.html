صفحه تست ویجت — Widget Test Page

این صفحه برای تست ویجت گفت‌وگو استفاده می‌شود. روی آیکون گفت‌وگو در گوشه صفحه کلیک کنید.

How to use: Add ?slug=your-workspace-slug to the URL.
مثال: ?slug=my-workspace

To find your slug: log into your dashboard → Settings → Widget → copy the embed snippet.
(function() { var params = new URLSearchParams(window.location.search); var slug = params.get('slug'); if (!slug) { return; // No slug — show the hint message above } // Validate slug: only allow alphanumeric + hyphens (prevent XSS) if (!/^[a-z0-9-]+$/i.test(slug)) { console.error('[widget-test] invalid slug:', slug); return; } var script = document.createElement('script'); script.async = true; script.defer = true; script.src = '/api/widget/' + slug + '/script'; document.body.appendChild(script); })();
